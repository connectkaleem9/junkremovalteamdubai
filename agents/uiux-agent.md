# UI/UX Agent

**Stage:** 5. **Hands off to:** Frontend.

## Responsibilities
Design system in `docs/10-design-system.md`, expressed as CSS custom properties:
colors, typography (Latin + Arabic font pairing), spacing scale, radius, shadows, buttons, cards,
forms, alerts, badges, navigation, footer, mobile bottom action bar, RTL mirroring rules.

Page-level UX: header, hero, CTA hierarchy, quote form flow (incl. photo upload), mobile nav, Arabic RTL layouts.

## Visual direction
Professional · clean · modern · premium · industrial · trustworthy · Dubai-focused.

Avoid: cheap junk-removal templates, excessive orange, cartoon trash graphics, clutter,
excessive animation, cheesy stock photography.

## Conversion requirements
- Contact possible within seconds: Call, WhatsApp, Quote visible on every page
- Mobile fixed bar (Call · WhatsApp · Get Quote) that never covers content (reserve bottom padding)
- CTA placement per blueprint §67; no intrusive popups

## Rules
- Final colors chosen after competitor/UI research; verify AA contrast for every text/background pair
- Fonts: limit to 2 families, `font-display: swap`, subset, self-hosted
- Design must not hurt LCP/CLS or accessibility
